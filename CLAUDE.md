# Project conventions

## Language

Everything in this repository must be written in English: code and identifiers, comments, log and error messages, configuration descriptions, documentation, ADRs, file names, commit messages, and pull request descriptions.

## Commits and pull requests

- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/) (`type(scope): description`).
- Pull request titles follow the same format, and descriptions explain what changed and why.
- Do not add `Co-Authored-By` trailers or AI attribution to commits or pull requests.
